## ✨ Design Philosophy & Key Features

* 🎨 **Strict 4-Color Luxury Sage Palette**:
  - `Primary Background:` `#25332B` (Deep Forest Sage)
  - `Accent Sage:` `#95C7A4` (Soft Glowing Sage)
  - `Soft Surfaces:` `#CFE8D6` (Frosted Sage Tint)
  - `Primary Text:` `#F5FAF7` (Editorial Off-White)

* 🎯 **Precision Custom Sage Cursor**:
  - Small solid sage dot (`#95C7A4`) + spring-animated outer ring.
  - Expands from 32px to 56–68px over interactive elements.
  - Magnetic attraction effect that gently snaps toward button centers.

* 🌌 **3-Layer Parallax Background & Noise Overlay**:
  - Layer 1: Top radial soft sage spotlight (`#95C7A4`).
  - Layer 2: Slow-drifting blurred radial sage blobs (`#95C7A4` & `#CFE8D6`) with mouse parallax.
  - Layer 3: Floating ambient depth dust particles.
  - Subtle SVG noise grain texture giving an expensive editorial print finish.

* 💊 **Floating Glass Pill Navbar**:
  - Fully responsive glass capsule navbar with active tab glowing pill indicator and central expanding underline.

* 🍏 **Apple Showcase Experience Hero**:
  - 92% oversized showcase card detailing ML Internship at **Futurense**, bullet points with checkmarks, technology chips, and mouse spotlight.

* 🖼️ **Behance Case Study Projects**:
  - Staggered vertical rhythm featuring **DocuMind AI**, **Student Performance Tracker**, and **Doom Scrolling EDA** with thumbnail zoom, card lift, and cursor spotlight.

* 📜 **Stacked Floating Stationery Certificates**:
  - Overlapping stationery cards rotating 2° on scroll/hover, linking directly to verified Google Drive credentials.

* 📬 **Luxury Contact Studio**:
  - FormSubmit API integration with token protection (`a5fce3205d4bd27b976ba3f1a820ccde`) delivering inquiries straight to `saptaparnisaha23@gmail.com`.

## 🚀 Local Development Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/saptaparnisaha23/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start local development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to [http://localhost:3000](http://localhost:3000)

5. **Build production bundle**:
   ```bash
   npm run build
   ```
